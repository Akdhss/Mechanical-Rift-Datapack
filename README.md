[ Mechanical Rift ]
This project is a wave based horde survival gamemode that can be easily be ported over through any custom map or arena.


[ Set up ] 
Use the functions within "set_placement" to set up and place the markers on where the game will be played.
The functions that contain the cardinal directions such as "east_spawn.mcfunction" will spawn the marker where enemies will spawn from.

"player_spawn.mcfunction" is the function that will spawn the marker where the players will spawn from when starting a run.
This marker is also the most important as most of the code of Mechanical Rift is tied to this entity.

"lobby_spawn.mcfunction" is the function that will spawn the marker where the players will spawn when a run ends.



NOTE: Setting up all markers is a REQUIREMENT as the game would not be able to run with it missing.
